# 产品需求文档（PRD）：WordFlow

## 1. 项目背景
- 为什么要做：中国英语学习者需要"可落地"的多模态学习工具，把内容输入 → 词汇积累 → 练习巩固 → 错题闭环串起来。
- 当前现状与缺口：已有前端骨架和 9 个学习页面，但所有数据用 Mock 维持；后端 API 与桌面壳均未实现；shared/docs/business-features.md 为空，业务文档缺失。
- 预期收益：MVP 内形成"前端可运行 + 后端可调用 + 桌面可打包"的最小闭环，支撑真实学习数据沉淀。

## 2. 目标用户
- 主要用户画像：单用户自托管，18–35 岁中国英语学习者，具备基础读写能力，目标为 CET/雅思/托福/日常提升；使用场景为桌面端为主、Web 端为辅。
- 次要用户 / 利益相关方：无。本期纯自用，不做多用户、不做 B 端。

## 3. 核心问题
- 用户真正想解决的一件事：在真实英文内容上完成"学 → 练 → 错 → 再学"的闭环，数据持久化在自己控制的服务器上。
- 不解决会怎样：前端页面再多，没有后端存储与桌面分发，学习数据无法持久，产品不具备可交付性。

## 4. 功能范围
### 本期 MUST
1. 后端 API 服务（Express + TypeScript + Prisma + PostgreSQL）：
   - 内容管理（文章/视频/播客元数据、分类、难度）
   - 内容爬取模块（RSS/YouTube/Twitter/网页解析 + 媒体下载 + 内置定时调度）
   - 词汇 CRUD + 间隔重复（SM-2/简易版）
   - 练习题 CRUD + 提交评分
   - 错题本 CRUD + 掌握度流转
   - 学习统计（热力图、单词增长、周报）
   - AI 代理层（服务端转发到 LLM，支持降级 Mock）
2. 前端接入真实 API（替换 Mock + Pinia stores 重构）
3. 桌面端 Tauri 壳（复用 Web 前端，接入原生能力：本地缓存、系统托盘、全局快捷键）
4. 基础部署：Docker Compose 本地开发 + 单服务器云端部署

2. 听力/阅读专项模块接口与前端联动
3. 设置持久化（主题、每日目标、提醒时间）
4. 基础错误处理与统一响应格式

### 本期 MAY（延后到压缩生命周期）

2. 内容推荐算法（基于协同过滤/知识图谱）
3. 移动端原生 App（iOS/Android）
4. 口语测评 / 语音识别
5. 社区/社交功能
6. 付费订阅 / 支付网关

## 5. 用户流程
### 主流程（Happy Path）
1. 打开应用 → 直接进入内容库
2. 浏览内容库 → 选择文章/视频/播客
3. 阅读/观看内容 → 遇到生词点击查词 → 加入词汇表
4. 完成内容后 → 触发 AI 生成练习题 → 作答 → 错题自动进入错题本
5. 进入闪卡复习 → 按间隔重复算法调度
6. 查看仪表盘 → 观察学习热力图、单词增长、周报

### 关键分支流程
- 无鉴权：所有接口公开访问，无需登录
- 内容加载失败：降级显示摘要 + 缓存旧内容
- AI 服务不可用：前端降级为本地规则生成题目（随机抽词填空）
- 桌面端离线：本地缓存学习进度，联网后同步

## 6. 页面与交互说明
前端已实现 9 个页面（Dashboard/Content/ContentDetail/Vocabulary/Examples/Practice/Mistakes/Settings/Listening/Reading），本期不做 UI 重构，重点：
- 保持现有路由与组件结构
- 将 api/*.ts 中的 Mock 替换为真实 HTTP 调用
- 统一错误处理与加载状态
- 重构 Pinia stores，把组件内状态提升到统一 store
- 桌面端：路由切 memory history + 添加 Tauri 原生交互（系统托盘、全局快捷键、本地存储）

## 7. 边界条件
- 无鉴权边界：所有接口公开，依赖网络层安全（非公开域名/VPN）
- 空内容库 → 显示占位图 + 触发爬取
- 词汇表超 10,000 词 → 分页 + 虚拟滚动
- 练习提交并发 → 幂等键防重复提交
- 弱网环境 → 前端缓存 + 后台重试
- 桌面端窗口关闭 → 最小化到托盘而非退出
- 媒体文件缺失 → 降级显示占位图 + 错误提示

## 8. 非功能性要求（NFR）
- 性能：API 平均响应 < 200ms，P99 < 500ms；前端首屏 < 2s
- 兼容性：Web 端支持 Chrome/Edge/Firefox 最新 2 版；桌面端支持 Windows 10+/macOS 11+
- 安全：AI 请求走服务端代理，不暴露 key；依赖网络层安全（非公开域名/VPN）
- 备份：数据库每日自动备份（PostgreSQL pg_dump）；media/ 文件夹同步备份
- 日志：服务端记录请求/错误日志，密钥/敏感信息不进日志

## 9. 验收标准
1. Given 后端启动，When 前端调用 /api/v1/content，Then 返回分页列表且与 Mock 数据结构一致
2. Given 内容库有 10 篇文章，When 用户浏览内容页，Then 正常展示
3. Given 用户收藏 5 个单词，When 进入闪卡复习，Then 按间隔重复算法出题
4. Given 用户答错 1 题，When 提交练习，Then 错题进入错题本且 masteryStatus=not-reviewed
5. Given 桌面端打包，When 点击关闭窗口，Then 最小化到系统托盘
6. Given AI 服务不可用，When 请求生成题目，Then 前端降级为本地随机题
7. Given 爬取任务执行，When 检查内容库，Then 新增文章/视频/播客条目且 media/ 文件夹有对应文件
8. Given 每日定时触发，When 检查日志，Then 爬取任务自动执行并更新推荐内容
