# 研究计划：高质量中英双语字幕视频源深挖（第二轮）

## 背景
第一轮结论：YouTube 可用但中文轨是机器翻译（且常缺简体）；TED 人工双语最优但数量有限；B 站无 CC；Vimeo/Coursera/Khan/BBC/VOA 排除。用户不满意现有双语质量，要求找"高质量中英双语字幕的高质量视频"。

## 本轮假设（待验证）
1. **人工英文 + LLM 中文** 组合：YouTube 有大量"人工英文 CC 字幕"的视频，WordFlow 已有 LLM 翻译管道（translator.ts），中文质量可远超 YouTube 机器翻译轨。这是最务实的兜底路线。
2. **国内可直接访问的带人工双语字幕平台**：网易公开课、每日英语听力、可可英语、CGTN、中国日报等，可能有现成的人工双语字幕，且大陆直连。
3. **教育平台**：可汗学院（绕过坏掉的 extractor 直接走官方 API）、MIT OCW、Coursera 免费课程、字幕组资源。

## 子任务分配
| 子代理 | 任务 | 核心产出 |

| A | 国内人工双语字幕平台调研 | 网易公开课/每日英语听力/可可英语/CGTN 等：是否有双语字幕、获取方式、大陆可达性、程序化抓取可行性 |
| B | YouTube 高质量路线验证 | 人工英文 CC 覆盖率、知名高质量频道（纪录片/课程）、"人工en+LLM zh"可行性 |
| C | 教育平台与字幕组资源 | 可汗学院 API 直连、MIT OCW、Coursera 免费、字幕组双语字幕获取 |
