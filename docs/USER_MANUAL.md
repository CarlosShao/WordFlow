# WordFlow 用户手册

> WordFlow 是一款面向中国英语学习者的多平台学习工具，帮助你通过阅读、听力、练习高效提升英语能力。

---

## 1. 简介

WordFlow 的核心理念是：**通过真实内容学习英语**。我们提供文章、视频、播客等多种形式的英文内容，配合智能词汇本、AI 练习、错题复习等功能，打造完整学习闭环。

**适用人群：** 中国英语学习者（CET/雅思/托福/日常提升）

---

## 2. 功能概览

| 模块 | 功能 |
|------|------|
| **仪表盘** | 学习统计、热力图、单词增长曲线、今日推荐 |
| **内容中心** | 浏览文章/视频/播客，支持搜索、筛选、收藏 |
| **词汇本** | 添加生词、间隔重复复习、掌握度追踪 |
| **练习系统** | AI 生成练习题、答题判分、错题自动记录 |
| **错题本** | 错题回顾、掌握度流转、错题统计 |
| **AI 助手** | 生成题目、错误分析、语境释义、周计划、词汇故事 |

## 3. 快速开始

### 3.1 注册与登录

1. 打开应用，点击"登录"
2. 输入邮箱和密码，或点击"使用 GitHub 登录"
3. 如果是新用户，点击"去注册"创建账号
4. 登录后自动进入仪表盘

### 3.2 开始学习

1. 在**内容中心**选择感兴趣的文章/视频/播客
2. 阅读/观看过程中，点击生词可快速查看释义
3. 将生词添加到**词汇本**，系统会自动安排复习
4. 完成内容后，进入**练习系统**做 AI 生成的练习题
5. 答错的题目自动进入**错题本**，定期复习

### 3.3 查看进度

- **仪表盘**：查看学习天数、词汇量、阅读时长等统计
- **热力图**：直观看到每天的学习活跃度
- **错题统计**：了解自己的薄弱环节

## 4. 模块详细说明

### 4.1 仪表盘（首页）

- **学习统计**：总词汇量、总阅读时长、总听力时长、连续学习天数
- **热力图**：过去一年的学习活跃度（颜色越深表示当天学习越久）
- **单词增长曲线**：词汇量随时间的变化趋势
- **今日推荐**：基于你的水平和兴趣推荐的学习内容

### 4.2 内容中心

- **浏览内容**：按类型（文章/视频/播客）筛选
- **搜索内容**：关键词搜索标题和内容
- **收藏内容**：点击收藏按钮，方便以后查看
- **内容详情**：阅读文章原文、查看翻译、播放视频/音频
- **手动添加**：粘贴文章 URL 或输入内容

### 4.3 词汇本

- **添加生词**：在内容详情页点击生词自动添加
- **复习列表**：根据间隔重复算法（SM-2）自动安排复习
- **掌握度追踪**：标记单词掌握程度（未复习/复习中/已掌握）
- **搜索词汇**：快速查找已添加的单词
- **词汇故事**：AI 生成记忆故事，帮助记忆

### 4.4 练习系统

- **获取题目**：AI 根据你学过的内容生成练习题
- **题型支持**：完形填空、阅读理解、语法题、听力题
- **答题判分**：提交答案后自动判分，显示解析
- **练习记录**：查看历史练习成绩和正确率
- **错题自动记录**：答错的题目自动进入错题本

### 4.5 错题本

- **错题列表**：查看所有答错的题目
- **掌握度流转**：未复习 → 复习中 → 已掌握
- **错题统计**：按题型、难度统计错误分布
- **错题分析**：AI 分析错误原因，给出改进建议

### 4.6 AI 助手

- **生成题目**：基于指定内容生成练习题
- **错误分析**：分析答题错误，解释原因
- **语境释义**：给出单词在具体语境中的含义
- **周计划**：生成下周学习计划
- **词汇故事**：生成助记故事
- **难度评估**：评估内容难度等级

## 7. 常见问题

**Q: 内容是从哪里来的？**
A: 内容来自公开的新闻网站（BBC/CNN/NYT）、社区（Reddit/Medium）、视频平台（YouTube/TED）、播客等，系统自动抓取并处理。

**Q: 词汇本中的单词怎么复习？**
A: 系统使用间隔重复算法（SM-2），根据你的掌握程度自动安排复习时间。掌握越好，复习间隔越长。

**Q: 练习题是哪里来的？**
A: 练习题由 AI 根据你学过的内容自动生成，每次练习题目都不同。

**Q: 错题会自动删除吗？**
A: 错题会一直保留直到你标记为"已掌握"。系统会定期清理长期未复习的内容。

**Q: 可以手动添加内容吗？**
A: 可以，在内容中心点击"手动添加"，粘贴文章 URL 或输入内容即可。
